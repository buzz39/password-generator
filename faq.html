Frequently Asked Questions

General questions about the site. For tool-specific questions — like how many combinations a 6-digit PIN has — see the FAQ on that tool's own page.

Is Password Generator really free?

Yes. There is no paid tier, account, or usage limit. The site may show limited advertising in the future to cover hosting costs, but the tools themselves stay free.

Do I need to create an account?

No. Every tool works immediately with no sign-up.

Does this site work offline?

Once a page has loaded, generation works without an internet connection, because it does not depend on any server.

Which browsers are supported?

Any modern browser that supports the Web Crypto API, which includes current versions of Chrome, Firefox, Safari and Edge.

Can I suggest a feature or report a bug?

Yes — see the Contact page for how to reach out.

Why should I trust this site with passwords?

The generator never transmits, logs or stores what it creates. The Security page explains exactly how this is implemented, and it can be independently verified using your browser's developer tools.
