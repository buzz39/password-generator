Privacy Policy

This policy describes exactly what this site does and does not collect. It is written to reflect the actual implementation, not a generic template.

Tool data — passwords, PINs and passphrases

Everything you generate stays on your device. It is created in your browser using the Web Crypto API and is never transmitted to us, stored on our servers, or written to any database. See the Security page for a full technical explanation.

Website analytics

This site does not currently run any third-party analytics or tracking scripts. If analytics are added in the future, they will be configured to record only anonymous usage patterns — such as which page was viewed or which tool was used — and will never record generated passwords, PINs or passphrases. This page will be updated if that changes.

Advertising

This site does not currently display advertising. If advertising is introduced, it will not be permitted to obscure or interfere with the password generator, and this page will be updated to describe the specific advertising technology used.

Cookies

This site does not currently set any cookies.

Hosting

This site is served as static files. The hosting provider may log standard web server access data (such as IP address and request timestamp) as part of normal infrastructure operation; this is outside the site's own code and is not used by us for tracking.

Changes to this policy

If what this site collects changes, this page will be updated to match. Last reviewed: September 2026.
